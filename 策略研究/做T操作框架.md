# 分时做T操作框架（量价 + MACD 三共振）

> **一句话**：对已有底仓做日内高抛低吸降本，只在水上金叉/水下死叉等三共振信号出现时动手，无信号就等。定位是**持仓管理维度，不是选股策略**——和 `strategies/` 里的 T+1 选股策略不冲突，是叠加在压仓底仓上的日内手法。

## 0. 定位与适用边界

- **定位**：持仓管理维度（非选股/开仓）。对已有底仓做日内高抛低吸，仓位归零回原只赚差价降本。
- **适用**：压仓底仓（生益科技/沪电股份等产业趋势龙头）的日内降本。
- **不适用**：超短仓（次日就走，无需做T）；**事件性急跌**（定增/暴雷/致命负面）——后者走风控纪律（急跌不急卖分批 / 定增应对流程），**不套用做T卖出规则**。
- **与项目策略关系**：`strategies/` 的反转低吸/缠论底分型是 T+1 选股策略（信号日买次日卖），做T是叠加在已持有底仓上的日内管理，两者维度不同、可共存。
- **项目能力边界**：本系统是离线日K回测看板，**无实时盘中分时行情**；分时数据仅新浪 5 分钟 K 线、回最近 ~41 天（`datasource.fetch_minute_raw`）。故项目本身不做盘中实时做T提示，做T分析由 Claude 基于本文档 + `fetch_minute_raw` 5 分钟历史 + 用户持仓分时图人工提供来完成。要做成实时提示功能需另加实时分时数据层（重，未规划）。

## 1. 制度前提（T+1）

A股 T+1，当天买的不能当天卖。做T须有**底仓**：

- **正T（先买后卖）**：低点买入 → 冲高卖出**原有底仓**（卖的不是当天买的那笔）
- **反T（先卖后买）**：冲高先卖持仓 → 回落买回
- **铁律**：买多少卖多少、卖多少买回多少，**仓位归零回原**，只赚差价降本

## 2. 三共振框架

三方面信号相互印证才动手，不单看金叉死叉：

| 维度 | 看什么 |
|---|---|
| 量价 | 量能是改变方向的关键（拉升放量/回调缩量=健康走势） |
| MACD | 红绿柱 + 黄白线 + 金叉死叉 + 背离 |
| 分时形态 | N 字上涨 / 闪电破位 |

**零轴 = 红绿柱交界处**。零轴之上=水上，之下=水下。

**有效信号只有两个**：水上金叉（买）、水下死叉（卖）。
水下金叉 / 水上死叉动能不足，**不算信号**，继续等。

---

## 3. 买点（正T，约 10% 仓位）

三确认**共振**才买：

1. **放量突破分时前高**
2. **该绿不绿**：红柱本该转绿却重回红柱且变长（上涨动能延续）
3. **N 字上涨形态**

---

## 4. 卖点（反T）

四类信号：

1. **量价背离**：价新高但量萎缩。
   - ⚠️ **有压力位**时缩量上涨=背离=卖点
   - **创新高后无压力位**时缩量上涨=主力锁仓=**还可买**
2. **顶背离**：价新高指标未新高。
   - 弱背离=黄白线走平；强背离=红绿柱面积缩小
   - **红绿柱比黄白线更敏感，先变**
3. **乖离过大**：现价与均价线差 >3% **且**缩量（单看 3% 不够）
4. **破位三共振**：放量跌破分时低点 + 水下死叉 + 闪电破位 → 果断卖

---

## 5. 量能总原则

- 成交量负责改变方向
- **一直缩量 = 方向没变 = 只能等**
- **放量下跌 = 水下死叉（卖）**
- **缩量下跌 = 才可能是底背离**

这是区分"该卖反T"还是"可能是底背离"的关键。

---

## 6. 避坑要点（作者多年实战经验）

1. **顶大于底**：A股天生易跌难涨。顶背离一次就可能跌；底背离可能两三次仍不涨，**第一次底背离"一倍不买"**
2. **底背离 ≠ 会涨**：承接只说明可能跌不下去，不等于会涨
3. **下跌趋势顺势做空，不逆势低吸**
4. **分时均线支撑是陷阱**：缩量回踩均线 ≠ 支撑有效；缩量=只有散户、主力没参与
5. **MACD 滞后**：同位置既像顶背离又像水上金叉时**用量能定**——放量拉升=水上金叉（黄白线没跟上才像背离），缩量往上=顶背离
6. 非百分百，会做错

## 7. 术语速查

| 术语 | 含义 |
|---|---|
| 水上/水下 | MACD 零轴（红绿柱交界）之上/之下 |
| 水上金叉/水下死叉 | 零轴上方金叉（买信号）/零轴下方死叉（卖信号），唯一有效两类 |
| 该绿不绿 | 红柱本该转绿却重回红柱且变长，买点信号 |
| 量价背离 | 价新高量萎缩（有压力位时），卖点 |
| 顶背离/底背离 | 价新高指标未新高（顶·卖）/价新低指标未新低（底） |
| 强/弱背离 | 指标与股价完全相反=强；一方走平=弱 |
| 乖离率 | 现价与分时均价线距离，>3% 且缩量算过大 |
| 正T/反T | 正T=低买高卖做多；反T=高卖低买做空；当天仓位归零 |

## 8. 与本项目数据的配合

做T是分时操作，本项目数据层能提供的辅助：

- **`datasource.fetch_minute_raw(sym)`**：新浪 5 分钟 K 线，回最近 ~41 天——可计算分时 MACD / 量价 / 形态的近似信号（非严格分时图，5 分钟降采样）
- **本地 ohlcv 日线**：判断个股是否处于多头趋势（做T只对多头持仓做正T，空头不做）
- **限制**：无实时盘中分时、5 分钟仅 41 天、东财 `push2his` 分钟历史在本机 IP 被断连（见 README 数据口径）

**实盘做T提示流程（Claude 基于本文档）**：

1. 用户提供持仓代码 + 当前分时图（截图），或让 Claude 拉 `fetch_minute_raw` 5 分钟历史
2. Claude 按第 2-6 节框架识别三共振信号
3. 输出买点（正T）/卖点（反T）/无信号等待 的判断 + 仓位建议（约 10%）
4. 事件性急跌场景切换到风控纪律（见 TRADING_STATE 定增应对流程 / 急跌不急卖）
